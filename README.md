# 🎵 Spotify Clone

A Spotify-inspired music streaming web application built using **HTML, CSS, and JavaScript**. This project recreates the core Spotify experience with playlist browsing, music playback controls, responsive design, dynamic song loading, volume control, and an interactive user interface. Inspired by Spotify's modern dark-themed design and functionality.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/JasminVansh11/spotify-clone.git
```

### Open Project

```bash
cd spotify-clone
```

### Run Locally

Use VS Code Live Server or any local server:

```bash
npx serve .
```

or

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```
